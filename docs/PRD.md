# PRD: 개인 개발 블로그 (Notion CMS 기반)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 개인 개발 블로그 |
| 목적 | Notion을 CMS로 활용한 개인 기술 블로그 구축 |
| CMS 선택 이유 | Notion에서 글을 작성하면 별도의 배포 작업 없이 자동으로 블로그에 반영됨 |

일반적인 블로그는 마크다운 파일을 로컬에서 관리하고 커밋/배포해야 글이 반영되지만, 이 프로젝트는 Notion 데이터베이스를 CMS로 사용하여 어디서든 Notion 앱으로 글을 작성·수정하면 웹사이트에 자동 반영되는 것을 목표로 한다.

## 2. 목표 (Goals)

- Notion에서 작성한 글을 별도 배포 과정 없이 웹에서 확인할 수 있다.
- 카테고리, 태그, 검색을 통해 원하는 글을 쉽게 찾을 수 있다.
- 모바일/데스크톱 어디서든 편하게 읽을 수 있는 반응형 UI를 제공한다.

## 3. 주요 기능

1. **글 목록 조회**: Notion 데이터베이스에서 발행된(Status: 발행됨) 글 목록을 가져와 최신순으로 표시
2. **글 상세 페이지**: 개별 글을 선택하면 Notion 페이지 본문을 블로그 포스트 형태로 렌더링
3. **카테고리별 필터링**: Category 속성 기준으로 글을 필터링하여 조회
4. **검색 기능**: 제목/태그 등을 기준으로 글을 검색
5. **반응형 디자인**: 모바일, 태블릿, 데스크톱 환경에 대응하는 레이아웃

## 4. 기술 스택

| 영역 | 기술 |
|---|---|
| Frontend | Next.js 15, TypeScript |
| CMS | Notion API (`@notionhq/client`) |
| Styling | Tailwind CSS, shadcn/ui |
| Icons | Lucide React |
| Deployment | Vercel |

## 5. Notion 데이터베이스 구조

| 필드명 | 한글명 | 타입 | 설명 |
|---|---|---|---|
| Title | 제목 | title | 글 제목 |
| Category | 카테고리 | select | 단일 카테고리 분류 |
| Tags | 태그 | multi_select | 복수 태그 |
| Published | 발행일 | date | 글이 발행된 날짜 |
| Status | 상태 | select | 초안 / 발행됨 |
| Content | 본문 | page content | Notion 페이지 본문 (블록 콘텐츠) |

> 웹사이트에는 `Status = 발행됨` 인 글만 노출한다.

## 6. 화면 구성 (IA)

| 화면 | 경로(예시) | 설명 |
|---|---|---|
| 홈 | `/` | 최근 글 목록 표시 |
| 글 상세 | `/posts/[slug]` | 개별 글의 상세 내용 표시 |
| 카테고리 | `/category/[category]` | 선택한 카테고리에 속한 글 목록 표시 |

## 7. MVP 범위

- Notion API 연동
- 글 목록 및 상세 페이지
- 기본 스타일링
- 반응형 디자인

MVP 단계에서는 검색 기능과 고급 카테고리 필터 UI는 최소 기능으로만 제공하고, 이후 반복 개선한다.

## 8. 구현 단계

1. **환경 설정**: Notion API 패키지(`@notionhq/client`) 설치 및 프로젝트 환경 변수 설정
2. **Notion 준비**: Notion 데이터베이스 생성 및 Integration API 키 발급/설정
3. **글 목록 페이지 구현**: 홈 화면에서 발행된 글 목록을 조회 및 표시
4. **글 상세 페이지 구현**: 개별 글의 Notion 본문을 블로그 포스트로 렌더링
5. **스타일링 및 최적화**: Tailwind CSS, shadcn/ui 기반 UI 다듬기 및 반응형 대응, 성능 최적화

## 9. 향후 고려사항 (Out of Scope for MVP)

- 댓글 기능
- 조회수/좋아요 등 인터랙션 기능
- 다국어 지원
- RSS 피드, SEO 고도화
